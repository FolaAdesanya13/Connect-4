## Requirements

- .NET 10 SDK

## Run

From the project directory:

```powershell
dotnet run --project Project.csproj
```

## How to play

Choose **PLAY** to start. Players take turns dropping red and yellow discs into
the seven-column board. The first player to connect four discs horizontally,
vertically, or diagonally wins. A full board with no winner is a draw.

Use **NEW GAME** to restart, **MAIN MENU** to return to the start screen, or
**QUIT** to close the game.
